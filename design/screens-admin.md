# 라운지핏 관리자 웹 — Stitch 화면 생성 프롬프트 (B군)

| 항목 | 내용 |
|---|---|
| 대상 도구 | Google Stitch (Web / Desktop) |
| 화면 수 | 10개 |
| 기준 뷰포트 | 1280 × 800 |
| 선행 문서 | PRD v1.0 / TDD 코어 / TDD 확장 |

## 사용 방법

1. **0장의 공통 시스템 프롬프트를 먼저 붙여 1개 화면을 생성한다.** 이후 화면은 스타일을 이어받는다.
2. A군(모바일)과 같은 세션에서 생성하지 않는다. 레이아웃 성격이 달라 서로를 오염시킨다.
3. 큰따옴표 문자열은 **확정 문구**이다. 임의로 바꾸지 않는다.
4. 관리자 화면의 사용자는 데스크 매니저다. 하루 수십 번 반복 조작하므로 **밀도가 높고 클릭 수가 적어야 한다.** 여백을 넓히지 않는다.

## B-4. 수업 등록 모달

