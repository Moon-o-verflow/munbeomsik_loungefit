# 라운지핏 회원 모바일 웹 — Stitch 화면 생성 프롬프트 (A군)

| 항목 | 내용 |
|---|---|
| 대상 도구 | Google Stitch (Mobile) |
| 화면 수 | 11개 |
| 기준 뷰포트 | 390 × 844 |
| 선행 문서 | PRD v1.0 / TDD 코어 |

## 사용 방법

1. **0장의 공통 시스템 프롬프트를 먼저 붙여넣어 1개 화면을 생성한다.** 이후 화면부터는 Stitch가 스타일을 이어받는다.
2. 각 화면 프롬프트는 독립 실행이 가능하도록 작성되어 있다. 결과가 어긋나면 0장을 다시 앞에 붙인다.
3. 큰따옴표로 감싼 문자열은 **화면에 그대로 들어가야 하는 확정 문구**이다. 임의로 바꾸지 않는다.
4. 한 프롬프트에 화면 1개만 요청한다. 여러 개를 묶으면 디테일이 뭉개진다.

## 0. 공통 시스템 프롬프트

```
필라테스·요가 스튜디오 체인 "라운지핏"의 회원용 모바일 웹 앱을 디자인한다.
390x844 모바일 뷰포트 기준이며, 30~50대 여성 회원이 주 사용자다.

[디자인 방향]
차분하고 정돈된 웰니스 톤. 화려한 그라디언트, 이모지, 과도한 그림자를 쓰지 않는다.
여백을 넉넉히 두고 정보 위계를 타이포그래피 크기와 굵기로만 구분한다.
카드는 얇은 보더(1px)와 미세한 라운드(12px)로 처리하고 무거운 드롭섀도를 쓰지 않는다.

[컬러]
배경 #FAF8F5 (웜 오프화이트)
카드/서피스 #FFFFFF
주 텍스트 #1C1A17
보조 텍스트 #7A736B
보더 #E8E3DC
액센트(주요 버튼, 활성 상태) #4A5D4E (딥 세이지)
액센트 연한 배경 #EDF1EC
경고/주의 #B4552D
비활성 #B8B2A9

[타이포그래피]
Pretendard 사용. 모든 텍스트는 한국어.
화면 제목 20px Bold / 섹션 제목 16px SemiBold / 본문 15px Regular
보조 정보 13px Regular / 배지·캡션 12px Medium

[컴포넌트 규칙]
주요 버튼: 배경 #4A5D4E, 흰 텍스트, 높이 52px, 라운드 10px, 가로 꽉 채움
보조 버튼: 흰 배경, 보더 1px #E8E3DC, 텍스트 #1C1A17
비활성 버튼: 배경 #EFEBE5, 텍스트 #B8B2A9
배지: 높이 24px, 라운드 6px, 12px Medium
바텀시트: 상단 라운드 20px, 상단 중앙에 4x36px 그랩 핸들
좌우 기본 패딩 20px

[하단 탭바]
높이 64px, 흰 배경, 상단 보더 1px #E8E3DC
탭 4개: "시간표" / "내 예약" / "이용권" / "알림"
활성 탭은 아이콘과 라벨 모두 #4A5D4E, 비활성은 #B8B2A9
아이콘은 선형(outline) 스타일, 채워진 아이콘 사용 금지

[표기 규칙]
시각은 "19:00" 24시간제
날짜는 "7/29(수)" 또는 "7월 29일(수) 19:00"
만료일은 "2026.09.30"
카운트다운은 "29:47"
```

## A-1. 로그인 (휴대폰 인증)

**목적** — 기존 회원만 진입한다. 회원가입 기능은 없다.

```
라운지핏 회원 로그인 화면을 디자인한다. 한 화면 안에서 2단계로 전환되는 구조이며,
Step 1과 Step 2를 별도 프레임 2개로 나란히 보여준다.

[Step 1 — 휴대폰 번호 입력]
상단 여백 80px 후 좌측 정렬로 브랜드 워드마크 "LOUNGEFIT" (18px, 자간 넓게, #4A5D4E)
그 아래 32px 간격으로 제목 "휴대폰 번호로 로그인" (20px Bold)
그 아래 8px 간격으로 보조 문구
"스튜디오에 등록하신 번호를 입력해 주세요" (13px, #7A736B)

40px 아래에 입력 필드 1개
- 라벨 "휴대폰 번호" (13px, #7A736B)
- 플레이스홀더 "01012345678"
- 높이 52px, 흰 배경, 보더 1px #E8E3DC, 라운드 10px
- 숫자 키패드 입력

하단 고정 영역에 주요 버튼 "인증번호 받기"
버튼 아래 16px 간격으로 중앙 정렬 안내
"등록되지 않은 번호는 데스크로 문의해 주세요" (12px, #B8B2A9)

[Step 2 — 인증번호 입력]
제목 "인증번호 입력" (20px Bold)
보조 문구 "010-1234-5678로 전송했습니다" (13px, #7A736B)

6자리 인증번호 입력 박스 6개를 가로로 균등 배치
- 각 박스 48x56px, 라운드 10px, 보더 1px #E8E3DC
- 입력된 칸은 보더 #4A5D4E 1.5px, 숫자 22px SemiBold
- 4번째 칸까지 입력된 상태로 표현하고 5번째 칸에 커서 표시

입력 박스 아래 16px 간격, 좌우 양끝 배치
좌측: "남은 시간 02:41" (13px, #B4552D)
우측: 텍스트 버튼 "재발송" (13px, #4A5D4E, 밑줄)

하단 고정 주요 버튼 "확인"

[Step 2 에러 상태도 함께 표현]
입력 박스 아래에 에러 문구 "인증번호가 올바르지 않습니다." (13px, #B4552D)
이때 입력 박스 보더는 #B4552D
```

## A-2. 시간표 (홈)

**목적** — 앱의 중심 화면. 수업 카드의 6가지 상태가 한눈에 구분되어야 한다.

```
라운지핏 시간표(홈) 화면을 디자인한다. 하단 탭바에서 "시간표"가 활성 상태다.

[상단 헤더]
좌측에 "시간표" (20px Bold), 우측에 알림 벨 아이콘(선형)과 미읽음 빨간 점

[지점 필터 칩]
헤더 아래 가로 스크롤 칩 4개: "전체" "강남점" "성수점" "판교점"
- 높이 36px, 라운드 18px, 좌우 패딩 16px, 13px Medium
- 선택된 "전체"는 배경 #4A5D4E, 흰 텍스트
- 나머지는 흰 배경, 보더 1px #E8E3DC, 텍스트 #7A736B

[날짜 스트립]
칩 아래 가로 스크롤 날짜 셀 14개
- 각 셀 폭 48px, 상단에 요일 "수"(12px), 하단에 일자 "29"(17px SemiBold)
- 선택된 날짜는 배경 #4A5D4E, 흰 텍스트, 라운드 12px
- 오늘 날짜는 일자 아래 3px 점(#4A5D4E) 표시
- 예약 오픈 전 날짜는 텍스트 #B8B2A9로 흐리게 처리
스트립 아래 우측 정렬 캡션 "7/29 ~ 8/12 예약 가능" (12px, #B8B2A9)

[수업 카드 리스트]
날짜 스트립 아래 세로 리스트. 카드 간격 12px, 좌우 패딩 20px
각 카드는 흰 배경, 라운드 12px, 보더 1px #E8E3DC, 내부 패딩 16px

카드 내부 구조:
- 좌측 상단: 시간 "19:00 - 19:50" (15px SemiBold)
- 우측 상단: 상태 배지
- 시간 아래 6px: 수업명 "1:4 기구 필라테스" (17px SemiBold)
- 그 아래 6px: 보조 정보 한 줄 "강남점 · 김지원 강사" (13px, #7A736B)

아래 6개 카드를 순서대로 배치해 상태 차이를 모두 보여준다:

1) 예약 가능 — 배지 "잔여 5/8", 배경 #EDF1EC, 텍스트 #4A5D4E
2) 잔여 임박 — 배지 "잔여 1/8", 배경 #FBF0EA, 텍스트 #B4552D
3) 마감(대기 가능) — 배지 "대기 2명", 배경 #F2EFEA, 텍스트 #7A736B
4) 내가 예약함 — 배지 "예약완료", 배경 #4A5D4E, 흰 텍스트.
   카드 좌측에 세로 3px 액센트 바(#4A5D4E)를 붙인다
5) 내가 대기 중 — 배지 "대기 2번", 흰 배경, 보더 1px #4A5D4E, 텍스트 #4A5D4E
6) 예약 불가 — 배지 "예약불가", 배경 #F2EFEA, 텍스트 #B8B2A9.
   카드 전체 투명도 55%, 수업명 아래에 사유 한 줄 추가
   "보유하신 수강권으로는 예약할 수 없는 수업입니다" (12px, #B8B2A9)

[하단 탭바]
공통 규칙대로 4개 탭, "시간표" 활성
```

## A-3. 수업 상세 바텀시트 (예약)

**목적** — 차감 횟수와 취소 마감을 예약 전에 반드시 인지시킨다.

```
라운지핏 시간표 화면 위에 올라온 수업 상세 바텀시트를 디자인한다.
뒤 배경은 시간표 리스트가 어둡게(투명도 40% 검정) 깔린 상태로 표현한다.

[바텀시트]
화면 하단에서 올라온 시트, 상단 라운드 20px, 흰 배경, 높이는 화면의 약 62%
상단 중앙에 그랩 핸들 4x36px (#E8E3DC)

[내용 — 좌우 패딩 20px]
상단에 수강권 종류 배지 "1:4 기구 필라테스" (배경 #EDF1EC, 텍스트 #4A5D4E, 12px)
그 아래 8px: 일시 "7월 29일(수) 19:00 - 19:50" (20px Bold)
그 아래 6px: "강남점 · 김지원 강사" (14px, #7A736B)

24px 아래 정원 현황 블록
- 흰 배경에 보더 1px #E8E3DC, 라운드 12px, 내부 패딩 16px
- 좌측 "예약 현황" (13px, #7A736B), 우측 "5 / 8명" (15px SemiBold)
- 그 아래 8px 간격으로 진행 바
  전체 폭 회색(#F2EFEA) 위에 62% 만큼 #4A5D4E로 채움, 높이 6px, 라운드 3px

16px 아래 정보 리스트 (각 행 높이 44px, 행 사이 구분선 1px #E8E3DC)
- "차감 횟수"      우측 "1회" (15px SemiBold)
- "예약 후 잔여"   우측 "6회" (15px SemiBold)
- "무료 취소 마감" 우측 "7월 29일(수) 16:00" (15px SemiBold, #B4552D)

리스트 아래 12px 간격 안내 박스
- 배경 #F7F5F1, 라운드 10px, 패딩 12px
- "취소 마감 이후에 취소하시면 횟수가 차감됩니다." (12px, #7A736B)

[하단 고정 버튼 영역]
상단 보더 1px #E8E3DC, 패딩 16px 20px
주요 버튼 "예약하기" (배경 #4A5D4E, 흰 텍스트, 높이 52px)
```

## A-4. 예약 실패 안내

**목적** — 7가지 실패 사유를 각각 다른 문구로 보여준다. 서버 메시지를 그대로 출력한다.

```
라운지핏 수업 상세 바텀시트의 "예약 실패" 상태 변형을 디자인한다.
A-3 바텀시트와 동일한 레이아웃을 쓰되, 하단 버튼 바로 위에 에러 안내 박스가 삽입된 형태다.

[에러 안내 박스]
- 배경 #FBF0EA, 보더 1px #EDD5C6, 라운드 10px, 패딩 14px
- 좌측에 원형 경고 아이콘(선형, 20px, #B4552D)
- 우측에 메시지 텍스트 (14px Medium, #B4552D)
- 아이콘과 텍스트 간격 10px, 텍스트는 2줄까지 자연스럽게 줄바꿈

[하단 버튼]
에러 상태에서는 주요 버튼이 비활성(배경 #EFEBE5, 텍스트 #B8B2A9)

아래 7가지 변형을 각각 별도 프레임으로 나란히 만든다.
메시지 문구는 아래 원문을 그대로 사용한다.

1) "예약이 정지된 상태입니다. 자세한 내용은 데스크로 문의해 주세요."
   → 버튼 라벨 "예약 불가", 비활성

2) "보유하신 수강권으로는 예약할 수 없는 수업입니다."
   → 버튼 비활성

3) "이용권 만료일 이후의 수업은 예약할 수 없습니다."
   → 에러 박스 아래에 보조 정보 한 줄 추가
     "이용권 만료일 2026.08.15" (12px, #7A736B)

4) "남은 횟수가 없습니다."
   → 버튼 비활성

5) "하루 예약 가능 횟수를 모두 사용하셨습니다."
   → 에러 박스 안 두 번째 줄에 "오늘 1 / 1회 사용" (12px, #B4552D)

6) "이번 주 예약 가능 횟수를 모두 사용하셨습니다."
   → 에러 박스 안 두 번째 줄에 "이번 주 3 / 3회 사용" (12px, #B4552D)

7) "정원이 마감되었습니다. 대기 등록을 이용해 주세요."
   → 이 경우만 예외적으로 하단 버튼이 활성 상태이며
     라벨은 "대기 등록하기", 배경 #4A5D4E
```

## A-5. 대기 등록 확인 바텀시트

**목적** — 선차감 방식을 반드시 이해시킨다. 이 화면의 설명 실패가 곧 CS로 이어진다.

```
라운지핏 대기 등록 확인 바텀시트를 디자인한다.
뒤 배경은 시간표 리스트가 어둡게 깔린 상태다.

[바텀시트]
상단 라운드 20px, 흰 배경, 높이 화면의 약 58%, 그랩 핸들 포함

[내용]
상단 배지 "정원 마감" (배경 #F2EFEA, 텍스트 #7A736B, 12px)
그 아래 8px: "7월 31일(금) 19:00 - 19:50" (20px Bold)
그 아래 6px: "강남점 · 1:4 기구 필라테스 · 김지원 강사" (14px, #7A736B)

20px 아래 대기 현황 블록
- 흰 배경, 보더 1px #E8E3DC, 라운드 12px, 패딩 16px
- 좌측 "현재 대기 인원" (13px, #7A736B)
- 우측 "2명" (15px SemiBold)
- 아래 8px: "등록하시면 3번째 순번입니다" (13px, #4A5D4E)

16px 아래 — 이 화면의 핵심 안내 박스
- 배경 #EDF1EC, 라운드 12px, 패딩 16px
- 제목 줄: 좌측에 정보 아이콘(선형 16px, #4A5D4E)
  + "대기 등록 시 횟수가 먼저 차감됩니다" (14px SemiBold, #4A5D4E)
- 그 아래 10px, 불릿 3줄 (13px, #4A5D4E, 줄간격 1.6)
  · "지금 1회가 차감되어 잔여 7회 → 6회가 됩니다"
```

## 부록. 생성 후 점검 항목

Stitch 결과물을 받은 뒤 아래를 확인한다. 어긋나면 해당 프롬프트의 문구 부분만 다시 강조해 재요청한다.

| 항목 | 확인 내용 |
|---|---|
| 문구 | 확정 문구가 임의로 바뀌지 않았는가 (특히 A-4 에러 7종, A-5 선차감 안내) |
| 상태 구분 | A-2 카드 6종의 배지 색상이 서로 구분되는가 |

| 마감 시각 | A-3 · A-7에 무료 취소 마감 시각이 노출되는가 |
| 카운트다운 | A-8의 숫자가 화면에서 가장 큰 요소인가 |
